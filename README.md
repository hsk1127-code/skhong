# 프로젝트 자료 관리

프로젝트마다 엑셀 통합문서 하나로 관리하던 자료를 그대로 옮겨 관리하는 프로그램입니다.
개요, 일정, 사양, BOM, 회의록, 날짜별 문의·답변 캡처, 변경사항, Revision을 한 화면에서 다루고,
여러 프로젝트의 현황은 통합 대시보드에서 봅니다.

## 사용 방법 (설치 필요 없음)

1. [`프로젝트자료관리.html`](프로젝트자료관리.html) 파일 하나를 내려받아 **더블클릭**합니다. (크롬 또는 엣지)
2. 왼쪽 **📥** 버튼으로 지금 쓰고 있는 프로젝트 엑셀 파일을 불러옵니다.
3. 작업 후 왼쪽 아래 **💾 백업**을 누르세요. 처음 한 번 `프로젝트자료관리.html`이 있는 폴더를 고르면, 그다음부터는 그 폴더 안의 `백업` 폴더에 `프로젝트자료_백업_날짜_시간.zip`으로 바로 저장됩니다. (크롬·엣지. 폴더는 왼쪽 아래 📁 **변경**으로 바꿀 수 있고, 📂 복원은 그 폴더에서 열립니다)

### 기존 엑셀을 불러오면

| 엑셀 시트 | 프로그램에서 |
|---|---|
| 개요 | 개요 탭 (설비/품목명, Project, 고객사, 입고, 사업 범위, 비고 등) |
| 일정 | 일정 탭: 한눈에 보기(단계별 막대 일정표, 오늘 선, 지연·진행 중·다음 일정 요약)와 표로 편집(기간·경과일·잔여일 자동 계산). 불러올 때 기준일 이전에 끝난 일정은 완료로 표시. 날짜 없는 세부 항목(` - AMR 주행` 등)은 바로 위 날짜 있는 일정의 상태를 따름 |
| SW 사양, HW 주요 Spec | 사양 탭의 사양 구분 (HW 자료 이미지 포함) |
| 그 밖의 날짜 없는 시트 (업무 Scope 정의, 설계 및 제작 조건, 시스템 사양, 통신사양 …) | 사양 탭에 시트마다 사양 구분으로 추가. 번호 제목(1.1. 환경 조건, ■ 설계)은 구분, 그 아래 문단과 작은 표(항목·내용·담당·비고)는 항목으로 정리하고 그림은 첨부 |
| 이름이 사양·사양서·Spec·Technical Sheet 인 날짜 시트 | 사양 탭 (메일 캡처·원본 첨부, 받은 날짜는 메모에, 넣어 둔 엑셀 사양서는 항목으로 읽음) |
| BOM, 소모품, 지정품_지급품 | 자재 탭 (소제목 행 유지) |
| 제출 자료, 변경사항, Revision | 각 탭 (제출 자료의 제출처는 개요의 고객사로 자동 입력) |
| `…회의록(날짜)` 시트 | 회의록 탭: 회의 정보, 내용, 실천 의제(담당자·기한·완료 체크) |
| `제목(2026.10.06)` 같은 날짜 시트 | 자료 이력 탭: 메일 캡처 이미지와 시트에 넣어 둔 원본 파일(xlsx, pptx)을 날짜별로 정리 |

### 주요 기능

- **통합 대시보드**: 프로젝트별 진행률과 종료 D-day, 일정표에 맞춘 상태(`기구설계 진행`, `전장 지연`, `시작 전`, `일정 완료`; 직접 고른 완료·보류가 우선), 지연된 일정, 2주 안에 시작하거나 끝나는 일정, 미완료 실천 의제, 최근 자료
- **자료 이력**: 메일 화면을 캡처해 **Ctrl+V** 하면 바로 등록되고, 파일은 끌어다 놓으면 됩니다. 이미지는 클릭하면 크게 보입니다.
- **설비별 BOM** (자재 탭 → BOM): 사업 범위(`Conveyor AMR : 2EA` 등)에서 설비와 대수를 만들고, 설비마다 **1대당 수량**으로 BOM 을 적으면 **총 수량(× 대수)** 이 자동 계산됩니다.
  - 설비 추가·이름·대수 변경·삭제, ⇄ 로 품목을 다른 설비로 이동, ↻ 사업 범위에서 다시 가져오기.
  - **📊 전체 합계**: 품목·모델명·업체명이 같은 부품을 모아 설비별 수량과 구매용 총 수량을 보여 줍니다.
  - 엑셀 내보내기는 설비별 BOM 시트(총 수량 = 1대당 × 대수 수식)와 BOM 합계 시트로 나뉩니다. 예전에 만든 BOM 은 첫 번째 설비로 옮겨집니다.
- **BOM 엑셀 가져오기·자동 정리** (자재 탭, 넣을 설비 선택): 업체에서 받은 BOM·메이커리스트 엑셀을 넣으면 머리글(`Item Name`/`품목명`, `Spec.`/`규격`, `Maker`, `Q'ty`, `Remark` 등)을 알아보고 표에 맞춰 넣습니다.
  - 미리보기에서 시트와 열 맞춤을 확인하고 바꿀 수 있습니다.
  - 소제목(전장, 본체부 등)으로 비어 있는 구분을 채우고, 같은 품목·모델·업체는 개수를 더해 한 줄로 합치고, 구분끼리 모읍니다.
  - 원본 파일은 함께 보관되고, 마지막 가져오기·정리는 **↩ 되돌리기**로 취소할 수 있습니다.
  - **설비별 시트**: 엑셀에 `AMR`, `충전기`처럼 설비마다 시트가 나뉘어 있으면 **시트별로 설비에 나눠 넣기**가 자동으로 켜집니다. 시트 이름으로 설비를 찾고(충전기↔Charger, AMR↔로봇 같은 말도 인식) 없으면 새 설비를 만듭니다. `(이전)…(날짜)` 같은 예전 시트는 빼고, 시트마다 넣을 설비를 바꿀 수 있습니다. 프로젝트 엑셀의 `BOM_AMR`, `충전기 BOM` 시트도 불러올 때 설비별로 나뉩니다.
- **회의록 엑셀 가져오기** (회의록 탭): 회의록 엑셀 파일을 고르거나 목록에 끌어다 놓으면 등록됩니다. 여러 파일을 한 번에 넣을 수 있습니다.
  - 기존 회의록 양식뿐 아니라 `일시`·`장소`·`회의명`·`논의내용`·`조치사항` 같은 다른 양식이나 "일시 : 2026.10.06" 처럼 한 칸에 적은 것도 읽습니다.
  - 원본 엑셀과 시트 안의 사진은 첨부로 보관되고, 같은 제목·날짜의 회의록은 건너뜁니다.
  - 등록하면 Revision에 `회의록: 제목`이 자동 기록됩니다. (직접 작성할 때는 제목을 입력하면 기록)
- **주요 일자** (개요): Kick Off 일자, 입고일자(=납품일자), Setup 완료일, Warranty(시작일 + 기간 → 종료일, 보증 중·남은 일수), 지급 완료일. 비워 두면 Kick-off 회의록·'납품' 일정·정산 완료일에서 자동으로 채우고, 완료 보고서도 같은 값을 씁니다. Warranty 는 **Warranty 시작일 + 설정한 기간(년)** 으로 계산하며, 시작일을 넣기 전에는 '시작 전'으로 표시됩니다.
- **정산 비율 설정** (개요 요약의 ⚙ 버튼): `30/60/10`, `선금30 중도금60 잔금10` 처럼 한 줄로 입력하거나 자주 쓰는 비율(30:60:10, 30:40:30, 50:50 …)을 고릅니다. 지금 비율을 ★ 자주 쓰는 비율로 저장해 다른 프로젝트에서도 쓸 수 있고, 합계가 100%가 아니면 마지막 단계로 맞출 수 있습니다. 단계 수가 같으면 비율을 바꿔도 정산일·상태는 유지됩니다.
- **계약·정산** (개요 → 정보 수정): 발주일, 발주금액, 실행 예가, 실행목표가, 실행가, **인건비**(제어·설계·전장·제작·Setup 각 M/D × M/D 단가로 자동 계산, 직접 고쳐 쓸 수도 있음. 실행가와는 따로 표시), **재경비·워런티비**((실행가 + 인건비) × 각자 설정한 비율), **실행가 합계**(실행가 + 인건비 + 재경비 + 워런티비, 합계 기준 이익도 표시) → 이익(발주금액 − 실행가 합계), 예가 대비(실행 예가 − 실행가, 이익률은 실행 예가 대비), 목표 대비(실행목표가 − 실행가) 자동 계산. 완료 보고서(PDF·엑셀)의 이익 분석도 같은 식, 발주금액(한글 금액 자동 표시), 부가세, 정산 비율(30:70, 30:40:30 등 빠른 입력, 단계별 금액 자동 계산, 정산일·상태). 요약 화면에 정산 진행 막대가 나옵니다.
- **미입력 표시** (개요 → 정보 수정): 비어 있는 칸은 노란색으로 표시되고, 맨 위에 '⚠ 미입력 N개' 목록이 나옵니다. 목록의 항목을 누르면 그 칸으로 바로 이동합니다. 다른 자료에서 자동으로 채워지는 칸은 제외합니다.
- **년도별 계약·정산 다운로드** (대시보드 → 💰 년도별 계약·정산): 완료 보고서(마감 보고서) 엑셀과 같은 양식으로, 고른 년도마다 그 해 모든 프로젝트를 열로 나란히 놓은 시트(프로젝트 내용·진행상황·정산관련·실행가 구성·이익)와 그 해 종합 시트를 만듭니다. 맨 앞 '년도별 합계'(건수·발주금액·실행가 합계·이익·수금액·미수금, 종합 시트를 수식으로 참조)와 단계별 '정산 내역' 시트도 함께 들어갑니다. 같은 창의 **🖨 PDF (인쇄)** 를 누르면 한눈에 보는 PDF 보고서를 만듭니다 — 1쪽: 핵심 숫자 · 년도별 막대(실행가 합계 + 이익 = 발주금액, 수금) · 프로젝트 한 줄 요약(이익률·수금 막대, 상태) / 년도마다: 요약 띠 + 마감 보고 표 + 종합 / 정산 진행 막대 (인쇄 창에서 'PDF로 저장'). 년도는 발주일 기준(없으면 Kick Off·첫 일정). 자료 폴더에 저장됩니다.
- **완료 프로젝트 마감 보고서 (엑셀)** (📄 버튼 → 📊 엑셀 보고서 다운로드): `프로젝트이름_완료보고서_날짜.xlsx`로 만들어, 처음 한 번 고른 **보고서 폴더**에 바로 저장합니다 (보고서 창에서 폴더 변경). PDF 로 저장할 때도 기본 파일 이름이 프로젝트 이름이 됩니다. 보고서의 일정 실적·미완료 일정은 일정 탭과 같은 기준(날짜 없는 세부 항목은 위 일정을 따름)으로 셉니다. 기존에 쓰던 마감 보고서 양식(프로젝트 내용 / 진행상황 / 정산관련, 이익(발주가 − 실행가)은 수식) + 종합 + 정산 내역·일정 실적·변경사항 시트.
  - 보고서 창의 **실행가 구성**에서 제어·설계·전장·제작·Setup M/D, M/D 단가, 인건비, 재경비·워런티비 비율을 넣으면 실행가 합계가 바로 계산되고, 엑셀에는 투입 M/D·인건비·재경비·워런티비·실행가 합계·합계 기준 이익(률) 행이 수식으로 들어갑니다.
  - Kick off일자(Kick-off 회의록), 납품일자(입고일자·납품 일정), 지급조건·입금완료일(정산 비율), 발주가, Warranty(Warranty 시작일 + 기간)는 자동으로 채우고, SET UP 완료일·실행목표가·실행가·이슈사항 등은 보고서 창에서 입력합니다.
  - 통합 대시보드의 **📊 완료 프로젝트 마감 보고서** 버튼은 완료된 프로젝트를 골라 열로 나란히 모은 보고서를 만듭니다.
- **프로젝트 완료 보고서 (PDF)** (📄 버튼 → 🖨 인쇄 / PDF): 개요, 계약·정산(원가 구성: 실행가·인건비·재경비·워런티비 비중 표와 발주금액 대비 막대, 실행가 합계 기준 이익), 이익 분석(예상·목표·실제·합계 기준 이익과 이익률), 일정 실적(완료 일자 = Setup 완료일, 없으면 보고서 완료일), 회의·의사결정, 변경사항, 자료 이력, 자재(BOM 선택), 미결 사항, 종합 의견을 A4로 인쇄하거나 PDF로 저장합니다. 일정에 완료 체크를 하면 실제 완료일이 기록돼 보고서에 들어갑니다.
- **사양 추가** (사양 탭 → ＋ 사양 추가): SW 사양·HW 주요 Spec 외에 기구·전장·성능·안전·통신/인터페이스·유틸리티/환경 사양이나 원하는 이름으로 사양 구분을 만듭니다.
  - 예시를 고르면 기본 항목(예: 안전 사양 → 비상 정지, 범퍼, Lidar 안전 영역 …)이 채워집니다.
  - 구분마다 항목 표(구분·항목·내용·검토), 도면·캡처 첨부, 메모가 있고 이름 변경·삭제가 됩니다.
  - 첨부를 잘못 넣었으면 ✕ 로 지우거나 ⇄ 로 다른 사양에 옮기거나 복사합니다.
  - **📥 엑셀에서 가져오기**: 고객 Technical Sheet 같은 엑셀의 머리글(영역·기술 요구 사항·요청·답변 등)을 알아보고 표에 넣습니다.
  - 엑셀 내보내기는 사양 구분마다 시트 하나로 나오고, 전체 검색에서도 찾아집니다.
- **엑셀처럼 표 편집**: 칸을 눌러 바로 고치고, 엑셀에서 여러 행을 복사해 붙여넣을 수 있습니다. 왼쪽 체크박스로 행을 골라 **선택 삭제**하거나 **전체 삭제**할 수 있습니다.
- **Revision 자동 기록**: 자료 이력·회의록이 **추가될 때만** 날짜·작성자·제목이 자동으로 남습니다 (그 밖의 작업은 기록하지 않음). 나중에 자료·회의록의 제목이나 날짜를 고치면 그 Revision 줄도 함께 바뀝니다.
- **회의록 인쇄/PDF**: 기존 회의록 양식으로 인쇄됩니다.
- **전체 검색**: 모든 프로젝트의 자료, 회의록, 일정, BOM 등을 한 번에 검색합니다.
- **엑셀로 내보내기**: 기존과 같은 시트 구성의 엑셀로 저장합니다. 날짜별 시트에는 캡처 이미지도 들어갑니다.
- **전체 자료 ZIP**: 엑셀과 첨부 원본 파일을 `첨부/2026.10.06_제목/` 같은 폴더 구조로 한 번에 저장합니다. 한글 파일 이름은 윈도우 기본 압축 풀기(CP949)와 반디집·7-Zip(UTF-8) 모두에서 바르게 보입니다.
- **보고서 폴더 / 자료 폴더** (왼쪽 아래): 파일로 연 프로그램에서는 브라우저가 내려받기 이름을 무시하고 'download' 로 저장하므로, 처음 한 번 고른 폴더에 정확한 이름으로 바로 저장합니다.
  - 📊 **보고서 폴더**: 완료 보고서(엑셀)만 저장됩니다.
  - 🗂 **자료 폴더**: 엑셀 내보내기·전체 자료 ZIP·첨부 파일 저장은 고른 위치 안의 `자료\프로젝트명\` 폴더에 저장됩니다. 폴더가 없으면 자동으로 만듭니다. (고른 폴더 이름이 이미 `자료`면 그 안에 바로 프로젝트 폴더를 만듭니다)

### 데이터 보관 주의

- **자동 백업**: 백업 폴더를 한 번 지정해 두면, 자료를 바꾼 뒤 2분이 지나면 `백업/자동백업_날짜.zip`(하루 한 파일, 최근 14개 보관)으로 자동 저장됩니다. 브라우저를 다시 켜면 권한 확인 때문에 왼쪽 아래에 **⏸ 자동 백업 멈춤 — 눌러서 켜기**가 나올 수 있습니다. 누르고 "방문할 때마다 허용"을 고르면 계속 켜져 있습니다.
- 데이터는 **브라우저마다 따로** 저장됩니다 (왼쪽 아래 `💻 Chrome에 저장됨`). 윈도우 업데이트 뒤 기본 브라우저가 엣지로 바뀌면 빈 화면이 나오는데, 이때는 전에 쓰던 브라우저로 열거나 백업 파일로 복원하세요. 빈 화면에 안내와 **📂 백업 파일에서 복원** 버튼이 나옵니다.

- 데이터는 **그 PC의 브라우저 안**(IndexedDB)에 저장됩니다. 브라우저의 "사이트 데이터 삭제"를 하면 지워집니다.
- **💾 백업**을 자주 하세요. 백업 파일은 실행 폴더의 `백업` 폴더에 쌓입니다. (폴더 지정을 지원하지 않는 브라우저에서는 내려받기 폴더로 저장) 백업한 지 7일이 지나면 왼쪽 아래에 경고가 표시됩니다.
- **다른 PC로 옮길 때**: HTML 파일만 복사하면 자료가 따라가지 않습니다 (자료는 원래 PC의 브라우저 안에 있음). 프로그램 폴더를 **`백업` 폴더째** 복사한 뒤, 새 PC에서 열고 **📁 실행 폴더에서 자료 불러오기**로 그 폴더를 고르면 가장 최근 백업으로 불러오고 그 폴더에 계속 자동 백업합니다. (같은 PC·같은 브라우저라면 HTML을 다른 폴더에 복사해도 자료가 그대로 보입니다)
- 같은 파일을 여러 창에서 동시에 열지 않는 것이 좋습니다. 열려 있으면 경고가 표시되고, 한 창에서 저장하면 다른 창은 최신 내용으로 새로 고쳐집니다. 고치지 않은 창이 예전 내용으로 덮어쓰는 일은 없고, 두 창에서 동시에 고친 경우에는 먼저 저장된 내용을 지키고 나중 창에 안내합니다.

## 개발

소스는 `app/src`에 있고, 아래 명령으로 단일 HTML 파일을 다시 만듭니다.

```bash
python3 app/build.py                                  # -> 프로젝트자료관리.html
python3 app/tests/make_fixture.py /tmp/fixture.xlsx /tmp/bom.xlsx /tmp/meeting.xlsx  # 테스트용 엑셀 (openpyxl, Pillow 필요)
node app/tests/e2e.js /tmp/fixture.xlsx /tmp/bom.xlsx /tmp/meeting.xlsx # 브라우저 종단 테스트 (playwright 필요)
```

| 파일 | 역할 |
|---|---|
| `app/src/zip.js` | ZIP 읽기/쓰기 (브라우저 내장 압축 사용) |
| `app/src/xlsx.js` | 엑셀 읽기(셀, 병합, 이미지, 삽입된 원본 파일)와 쓰기(이미지 포함) |
| `app/src/store.js` | IndexedDB 저장, 첨부 파일, 백업/복원 |
| `app/src/model.js` | 화면 구성 정의, 일정 계산, 엑셀 불러오기/내보내기 규칙 |
| `app/src/app.js` | 화면 |

> 이전 버전(`docmanager/` Python 서버, `standalone/`, `프로젝트문서관리.html`)은 일반 문서 대장 방식의 초기 버전입니다.
